# Q1 - Interactive Product Calculator

## Task
Create a webpage containing a product name, quantity, and price. Using JavaScript
functions and event listeners, calculate the total price dynamically whenever the
quantity or price changes without refreshing the page.

## Files
- `index.html` - Webpage structure and input fields.
- `style.css` - Basic page styling.
- `script.js` - Calculation, validation, DOM manipulation, and event listeners.

## Run
Open `index.html` in a web browser.

## Formula
Total Price = Quantity × Price per Unit

## Validation
Quantity and price must be valid non-negative numbers. The total is updated
automatically whenever either value changes.
