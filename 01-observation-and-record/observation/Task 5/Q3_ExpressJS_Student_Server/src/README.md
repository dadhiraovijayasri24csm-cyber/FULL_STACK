# Q3 - Express.js Student Server

## Task
Create a basic Express.js server with routes `/`, `/students`, and `/about`.

## Routes
- `/` - Displays the home page and available routes.
- `/students` - Returns a list of five students in JSON format.
- `/about` - Displays information about the application.

## Files
- `app.js` - Express.js server and routes.
- `package.json` - Project configuration and Express dependency.

## Run

Install dependencies:

```text
npm install
```

Start the server:

```text
npm start
```

Open:

```text
http://localhost:3000
```

## HTTP Method
The application uses the HTTP `GET` method for all three required routes.
